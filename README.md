# 삼국지 영걸전 — 유비전 (웹 · 모바일)

Koei 『삼국지 영걸전』(1995, PC/한국어판)을 원작 공략 자료를 바탕으로 최대한 비슷하게 재현한 턴제 전략 웹게임.
순수 HTML/CSS/JS + Canvas, 프레임워크 없음, 세로 휴대폰 화면 최적화.

## 실행
`index.html`을 브라우저로 열거나 `python3 -m http.server`로 서빙. 진행 상황은 localStorage에 저장.

## 구조
- `index.html` / `css/style.css` — 코에이식 창(남색 바탕·금색 이중 테두리, Galmuri 픽셀 폰트 CDN) · 스크롤 지도 · 장수 정보창 · 지도 위 팝업 명령 메뉴(공격/책략/도구/대기/취소) · 진영/상점/대화/전투 오버레이
- `js/data.js` — 원작 시스템 데이터: 지형, 병종 18종, 상성, 승급, 책략 36종+유비 전용, 습득표, 아이템(무기·병법서·말·소모품·승급·전직), 아군 장수 능력치, 적장 능력치
- `js/stages.js` — 스테이지(서장 사수관·호로관, 1장 1막 신도/광천·거록/청하·계교, 1장 2막 북해·서주·소패(화친 분기)). 16×20 지도, 적 배치·레벨, 원군, 승리조건, 일기토, 보물고, 대사, 분기, 가입 장수
- `js/logic.js` — DOM 없는 순수 로직(Node에서 테스트 가능): 능력치 공식, 이동(Dijkstra, 병종별 지형 제한), 공격 범위(인접4/8·궁·연노·발석), 피해·사기·반격, 경험치, 책략 범위·판정·피해, AI(능동/고정/수동)
- `js/battle.js` — 원작식 전투 장면: 부대 단위(장수+병사 최대 6명, 병력 비율만큼 표시) 돌격(행군 보브·흙먼지)·충돌(섬광·베기 궤적·불꽃·피격 적색)·화살 일제사격(그림자·명중 박힘)·책략 효과(화염/파도/낙석 + 파티클)·병사·장수·군기 쓰러짐. 지형별 배경(성벽·성문·숲·마을·막사·목책·강·다리·산·창고)과 날씨(해·구름·비)를 반영. 코에이식 HUD(초상화·병력 숫자·바·피격 깜빡임)
- `js/story.js` — 오프닝·장 삽화·엔딩 장면 플레이어: 동영상(`img/story/opening.mp4`, 삽화 4장+내레이션+자막, `img/render_opening.py`로 ffmpeg 렌더) → 못 틀면 삽화 장면으로 대체. 삽화는 켄 번즈 카메라 + 한 글자씩 자막 + edge-tts 한국어 내레이션(`img/story/*.mp3`). 스테이지는 `stages.js`의 `art` 키로 삽화를 지정
- 지도 위 효과(`game.js` addFx/drawFx): 전투 장면을 끈 상태의 피격·책략·회복·레벨업 파티클, 비 오는 턴의 빗줄기
- `js/game.js` — 진행 상태(로스터·금·분기 플래그), 진영 화면(출격 선택/상점/장수 아이템), 턴 진행(아군→우군 NPC→적군), 날씨, 회복 지형, 혼란, 보물고, 도달 승리, 일기토, 저장
- `img/` — AI 생성 레트로 도트 에셋: 지형 타일 16종(초원·황무지·다리·성채·병영·보물고·군량고·성문·성벽 포함), 병종 스프라이트 12종, 장수 초상화 18종, 타이틀. `img/raw/` 원본, `img/process_assets.py` 가공 스크립트(마젠타 키잉·영역 성장·최대 성분 유지)
- `docs/` — 원작 조사 보고서 4종 + 일본 공략 wiki 추출본(`raw_stages_jp.txt`)

## 원작 재현 규칙 (docs/research_*.md 기준, PC판)
- 능력치: 무력·지력·통솔(고정) + Lv·경험치·병력·사기·책략치
- 공격력 = ((4000/(140−무력) + 병과공격×2 + 사기)×(Lv+10)/10)×(100+무기%)/100, 방어력은 통솔·병법서로 동일
- 피해 = (공격력 − 방어력×상성(0.75/1.25)/2)×(100−지형%)/100, 항상 명중, 반격은 흉적·의적·무도가만(확률 무력/150, 피해 ½)
- 사기 감소 = 피해/(Lv+5)/3, 사기<30이면 혼란 가능, 사기 0 = 퇴각. 병력 0 = 퇴각(다음 전투 복귀), 유비 퇴각 = 패배
- 경험치: 공격 (상대Lv−내Lv+3)×2(≤16) / 고레벨 공격 4, 격파 총대장 48 · 고레벨 32 · 64/(차+2), 100으로 레벨업, 일기토 승리 Lv+1, 특정 승리조건 생존자 +50
- 책략치 = (Lv+10)×지력/40(≤255), 책략 피해 = 능력×2 − 상대능력 + 위력, 화계 숲 +25%·비 불가, 수계 비 +25%, 군악대 인접 시만 회복
- 지형: 초원·마을 5, 병영 10, 숲 20, 산·성채 30. 기병 숲 불가, 산은 적병·무도가·이민족·맹수사만. 마을·성채·병영 병력 150+ 회복
- 승급 Lv15/30 아이템(상점), 전직 아이템, 무기/병법서/말은 소지만으로 적용(최고 1개), 1인 8칸, 매각 75%
