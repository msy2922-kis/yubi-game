## 공식 (PC판)
- 공격력 = ((4000/(140−무력) + 병과기본공격×2 + 사기) × (Lv+10) / 10) × (100+무기%)/100
- 방어력 = ((4000/(140−통솔) + 병과기본방어×2 + 사기) × (Lv+10) / 10) × (100+병법서%)/100  (검산: 유비 Lv1 단병 사기100 → 265)
- 물리피해: 상성 유리 방어×0.75 / 불리 ×1.25 → (공격력 − 방어력/2) × (100−지형%)/100 → 반격이면 /2 → 최소 1, 명중 100%, 난수 없음.
- 지형%: 평지/다리/황무지 0, 초원 5, 마을 5, 병영 10, 숲 20, 산 30, 성채 30.
- 사기감소 = 피해/(방어Lv+5)/3 (최소1). 사기 <30 → 60% 혼란. 사기 0 → 퇴각.
- 반격(PC): 적병계·무도가만, 공격측이 적병·무도가·기병·이민족·맹수사일 때만 받음, 확률 무력/150, 피해 1/2.
- 책략: 최대책략치 = (Lv+10)×지력/40(≤255). 책략능력 = 지력×Lv/50 + 지력. 공격책략 피해 = 공격측능력×2 − 방어측능력 + 기본위력 (+rand 피해/50; 지원계 피격 /2; 숲 화계 +25%, 비 수계 +25%). 성공: rand(0~지력×Lv/100+지력) > 방어측 동식/4. 회복 = 기본 + 지력×Lv/20.
- 책략 위력/소모: 초열 200(4)/화룡 600(8)/업화 1000(12~16); 소용돌이 300(6)/탁류 700/해일 1100; 낙석 400(8)/산사태 800/토석류 1200(16); 견제 20(4)/도발 30(8)/위압 40(16); 거짓정보(8)/위병(16)/위장(24); 원조 600(6)/보급 1200(10)/구제 1800(14); 격려 30(4)/응원 40(8)/고무 50(12); 유비 전용 인덕(10)/의덕(18)/애덕(28)/대덕(50).
- 책략치 회복(PC): 인접 군악대만 (군악대Lv/10 /턴).
- 경험치: 공격Lv≤방어Lv → (방어Lv−공격Lv+3)×2 (≤16); 공격Lv>방어Lv → 4. 격파: 총대장 +48; 고레벨 +32; 동급/저레벨 64/(공격Lv−방어Lv+2). 보조책략 8, 군악/수송 회복 12. 100→레벨업(잉여 리셋). 일기토 승리/설득 = Lv+1. 특정 승리조건 달성 시 생존 전원 +50.
- 자동회복: 마을·성채 = 병력+사기, 병영 = 병력. 병력 150+rand(0~10)×10 /턴. 사기 통솔/10+rand(1~5).
- 혼란 해제: rand(0~99) < (통솔+사기)/3. 연전(장판파 2연전, 업 3연전) 사이 회복 없음.
- AI: 01 능동형, 02 고정형, 03 수동형(범위 진입 시 반응). 행동가치 = 피해 + 병력/6 + 지형/5; 병력 40% 미만이면 회복지형으로.
- 날씨: 맑음/흐림/비, 매 턴 변동.

## 퇴각·게임오버·턴 구조
- 병력 0 또는 사기 0 → 퇴각(영구 사망 아님, 다음 전투 복귀). 이벤트 사망 예외(황충·엄안·방통·관우 분기). 유비 퇴각 = 게임오버. 턴 제한(30~70) 초과 = 패배.
- 명령: 이동 → 공격 / 책략 / 도구 / 대기. 네임드 공격 시 일기토 이벤트. 유비 설득 이벤트 18회. 출전 최대 15명(전투별 상한).
- 아이템 1인 8개. 무기 +10~24%(삼첨도·칠성검·사모 10, 청룡언월도 12, 의천검 14, 자웅일대검 16, 방천화극 18, 청강검 20, 영걸검 22, 패자검 24). 병법서 방어 +15~22. 말: 조황비전 +1, 적로 +2, 적토마 +3 이동. 회복 보물: 원군보고·칙명서·옥새.
